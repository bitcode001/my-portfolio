> Everything in JavaScript is an Object!

Well in JavaScript, almost everything you work with behaves like an object — from arrays and functions to even primitive types.

Have you ever wondered how you could assign a string to a variable and magically you can now access a method from inside that string variable?

```js
JavaScript

const a = "Apple"
a.toUpperCase() // APPLE
typeof a // 'string'
```



Let’s unpack this powerful concept and see what does it really means.
